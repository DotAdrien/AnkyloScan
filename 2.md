## 🏢 Why AnkyloScan for your SMB?

Most small and medium-sized businesses don't have a dedicated security team or the budget for enterprise-grade monitoring tools. Yet the threat is real: open ports, outdated services, and unpatched vulnerabilities are the most common entry points for attackers.

**AnkyloScan was designed with this reality in mind.**

It is a lightweight, fully self-hosted solution that gives your organization a first layer of real network security — without requiring any cybersecurity expertise to deploy. You only need a machine with Docker installed.

In less than 5 minutes you get:

- A **live dashboard** showing all active hosts and open ports on your network.
- **Automated vulnerability detection** using Nmap scripts and CVE databases.
- **Security log collection** from your Windows and Linux machines via agents.
- **Email alerts** whenever something suspicious is detected.
- **Scheduled scans** so your network is checked regularly without any manual action.

No complex configuration, no external SaaS subscription, no data leaving your infrastructure.

## ✨ Features

### 🔍 Network Scanning (3 modes)

| Mode | Description | Use case |
|---|---|---|
| **Quick Scan** | OS detection + common ports (`-O -T4`) | Daily check, fast overview |
| **Security Scan** | Full port range + OS fingerprinting (`-p- -T4 -O`) | Weekly audit |
| **Full Scan** | All ports + service versions + CVE detection via `vulners` & `vuln` Nmap scripts | Deep security audit |

All scans run in the background — the interface remains responsive while the scan is in progress. Results are stored in the database and available at any time from the history.

### 📊 Web Dashboard

A clean, browser-based interface accessible on port `8000`. No installation required on client machines — just open a browser.

- Real-time scan status and history
- Detailed results per host: open ports, detected services, OS fingerprint
- CVE listings with severity when detected (Full Scan)
- Scan report download

### 🕵️ Unified Agents (Windows & Linux)

Deploy lightweight agents on your machines to collect **Windows Security Event Logs** and forward them to AnkyloScan in real time.

Each agent is authenticated via a **unique token** generated at download time. The server rejects any log submission from an unknown token, preventing spoofing.

Available agents:
- `InstallAnkyloAgent.ps1` — Windows agent via PowerShell (Active Directory / domain events)
- `InstallAnkyloAgent2.ps1` — Windows agent, alternate collection method
- `agent3.sh` — Linux agent

Logs are deduplicated (same event within 1 minute is not inserted twice) and displayed in the **Logs** view of the dashboard.

### ⏰ Scheduled Scans

Configure automatic recurring scans directly from the interface:

- Choose scan type (Quick / Security / Full)
- Set frequency in hours
- The scheduler runs in the background and launches scans automatically

The schedule persists across restarts via a configuration file.

### 📧 Email Notifications

AnkyloScan sends email alerts in two situations:

1. **Scan completed** — a summary report of discovered hosts and vulnerabilities is sent to configured recipients.
2. **Agent log alert** — when an agent forwards a security event, an email notification is triggered.

### 🔐 Authentication & Security

- Admin account protected by **JWT tokens**
- Passwords hashed with **bcrypt**
- Agent communication secured by **unique per-agent tokens**
- The admin password is randomly generated at first launch via `openssl rand`

┌───────────────────────────────────────────────────┐

│  ┌─────────────┐      ┌──────────────────────┐    │
│  │  Frontend   │      │       Backend        │    │

**3 Docker containers:**

| Container | Role | Port |
|---|---|---|
| `frontend` | Static web UI served by Nginx | `8000` |
| `backend` | FastAPI REST API + Nmap runner | `8001` |
| `db` | MySQL 8 — stores scans, logs, agents | `3306` |

## 🚀 Quick Start

### Prerequisites

- A Linux machine (physical, VM, or VPS) on the network you want to monitor
- Docker and Docker Compose installed

```bash
sudo apt update -y && sudo apt install -y docker.io docker-compose
```

### Installation

```bash
# Clone the repository
git clone https://github.com/DotAdrien/AnkyloScan
cd AnkyloScan

# Generate a secure random admin password
echo "ADMIN_PASSWORD=$(openssl rand -base64 32)" > .env

# Build and start all containers
sudo docker compose up --build
```

The `welcome` container will print your credentials in the terminal output:

```
--------------------------------------------
🦖 AnkyloScan is ready! 🛡️
URL    : http://localhost:8000
--------------------------------------------
```

Open `http://<your-server-ip>:8000` in any browser on your network.

> **Tip for SMBs:** Install AnkyloScan on a dedicated machine (even a small server or repurposed PC) and expose port `8000` only on your internal network. This way the dashboard is accessible to your IT team without being reachable from the outside.

## 🕵️ Deploying Agents

Agents allow AnkyloScan to receive security event logs from your machines in real time.

### Windows Agent

1. Log into the AnkyloScan dashboard.
2. Navigate to the **Agents** section.
3. Click **Download Windows Agent** — this generates a PowerShell script with a unique token pre-filled.
4. Run the script on the target Windows machine as Administrator:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
.\InstallAnkyloAgent.ps1
```

The agent will start forwarding Windows Security Event Logs to AnkyloScan immediately.

### Linux Agent

Download `agent3.sh` from the Agents page and run it on the target machine:

```bash
chmod +x agent3.sh
sudo ./agent3.sh
```
